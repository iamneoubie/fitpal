CONTEXT DIAGRAM
have four main external entities which are the Customer, Restaurant, Delivery Rider,
and Administrator.

DATA FLOW DIAGRAM
we have the ADMINISTRATORS, that can logs to the system then access the admin desktop to
verify registration. proceed to the CUSTOMER, CUSTOMER need register to the system and after
the verification they access the order menu and customise the order
next RESTAURANT need to register to the system same as the customer after that they can access the kitchen to update the order and to assign the rider
next for the DELIVERY RIDER need to register to the system same as customer after that they can access the deliveries and accept the assign order

USE CASE DIAGRAM
ADMIN
can access the view analytics, manage user, verify application
for the CUSTOMER have the to
give feedback, browse & filter menu, manage cart & order also track the order
for the DELIVERY RIDER have
manage deliveries and update the delivery status
Last for the RESTAURANT have Kitchen Queue, update order status and view the order details

Process Flow
ADMINISTRATORS
view information, monitor users, verify accounts, and manage their profile.
CUSTOMER
order the foods, customise the order, proceed to check out to process their order.
RESTAURANT can view incoming customer orders through the Kitchen Queue, inspect the ordered products, quantities, customer customizations, and special instructions, and update the status order
RIDER can login to the system, go to online status to receive the assign order from the restaurant and deliver to the customer.

SYSTEM ARCHITECTURE
PRESENTATION LAYER: it for UI and system navigation
Application Layer: it is the front end and handles all business logic
Data Layer: it is the Storage and Queries
